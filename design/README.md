# Brand sources

The mark (monstera leaf + diagnostic pulse) is generated from
`icon-source.js::markSVG()`. `export-source.html` renders it to PNG at any size
via canvas; the shipped set in `public/` is:

  icon.svg            favicon + manifest (any)
  icon-192.png        manifest (any)
  icon-512.png        manifest (any)
  icon-maskable-512.png  manifest (maskable -- art inset to 72% for the
                      circular safe zone)
  apple-touch-icon.png   iOS home screen (full-bleed square; Apple rounds it)
  og-image.png        1200x630 social share card, regenerated by
                      `og-source.html` (canvas, fonts via Google Fonts)
